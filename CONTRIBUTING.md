# Contributing

Contributions are welcome! Please follow these guidelines to keep the codebase clean and maintainable.

## Development Workflow

1. Fork the repository and clone your fork locally.
2. Create a new feature branch:
   \ash
   git checkout -b feature/your-feature-name
   \\n3. Link your local package for development testing:
   \ash
   npm link
   \\n4. Commit your changes using conventional commit standards (e.g., eat: ..., ix: ...).
5. Push to your branch and open a Pull Request.

## Code Standards
- Keep terminal output clean, professional, and free of emojis.
- Rely on native Node.js modules where possible to keep dependencies lightweight.
